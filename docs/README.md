# Everything Documentation

Welcome to the Everything documentation.

## What Is Everything?

_Everything_ defines what objects, properties, and structures are. To work with them, you can use the [`everything_structures` crate](../crates/everything_structures/). You can serialize them via the [`everything_structures_ff` crate](../crates/everything_structures_ff/) (file format).

This serves as a basis for the _Everything universal data model_ which is an interpretation of some structures and abstract objects.

First, read about [the structures](./structures.md) and then read [the data model](./data%20model.md).
