## Model Architecture

Lotus is a very dynamic data store, but also has static type checking built-in.

Lotus has values; a value can be one these types:

- Object (reference)
- Integer
- Decimal
- ...

_Object_ is a special value type. It is a "reference" to an object.

### Constraints

First of all, there are type constraints. Then there are association constraints. Then there are uniqueness constraints.
