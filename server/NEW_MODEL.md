# New Model

This document describes the data model and abstractions of Bird, along with their corresponding implementations in the database and program. But it does not state, _why_ things were modelled as they were.

## Overview

At a high level, Bird allows you to do some things. You can

- store files (pieces of binary data). Each file is given a numerical identifier (a number).
- create types, that allow you to describe your files.
- "tag" a file with a type.
- create directories that hold files or other directories.
- manage, track, version, move, describe, tag anything that is in Bird. You cannot tag tags.
- create and manage: users, groups and access tokens, down to the finest detail.
- query properties of files (primarily images) that usually would require reading every file on disk.

## Types And Tags

There a few primitive types. These types are the building block for creating new types. They cannot be applied as tags

| ID | Name        | Description                                                                                                       | Corresponding SQLite Column Type |
|----|-------------|-------------------------------------------------------------------------------------------------------------------|----------------------------------|
| 1  | `Object`    | An object ID, guaranteed to be valid.                                                                             | `INTEGER`                        |
| 2  | `Decimal`   | A 64-bit floating point number.                                                                                   | `REAL`                           |
| 3  | `Integer`   | A 64-bit integer.                                                                                                 | `INTEGER`                        |
| 4  | `String`    | A string of characters.                                                                                           | `TEXT`                           |
| 5  | `Duration`  | A duration of time, stored as a signed 64-bit integer describing the elapsed milliseconds.                        | `INTEGER`                        |
| 6  | `DateTime`  | An absolute time stamp, stored as a signed 64-bit integer describing the elapsed milliseconds after Jan. 1st 1970 | `INTEGER`                        |
| 7  | `Boolean`   | `true` or `false`.                                                                                                | `INTEGER`                        |
| 8  | `Character` | A single unicode code point.                                                                                      | `INTEGER`                        |
| 9  | `URL`       | A string but matching the URL scheme.                                                                             | `TEXT`                           |
| 10 | `Binary`    | A binary piece of data, a Blob.                                                                                   | `BLOB`                           |
| 11 | `Color`     | A CSS color.                                                                                                      | `TEXT`                           |
| 12 | `Email`     | A string that matches the email scheme.                                                                           | `TEXT`                           |
| 13 | `User`      | A user id.                                                                                                        | `INTEGER`                        |
| 14 | `Group`     | A group id.                                                                                                       | `INTEGER`                        |
