# The Everything Project

_Everything_ defines a **universal data format**, along with an interpretation that allows for **storing abstract knowledge** and **arbitrary, structured data**. It can be used as **knowledge bases**.

This project contains a few libraries to interact with Everything at different levels. If you don't want to use a library, there is a RUDIMENTARY [command line interface](./crates/everything_cli). You can run the cli from top level with:

```sh
cargo run --release -p everything_cli
```

More info at crate level.

**For an introduction to Everything, PLEASE read [the docs](./docs/README.md).**
