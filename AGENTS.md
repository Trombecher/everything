# Agents.md

_Everything_ is a database for storing arbitrary knowledge. It uses a highly flexible and reflective data model paired with a functional programming language / computation system.

## Documentation

Docs are found in `docs/public`.

### Design

Many design decisions have been discussed frequently in `docs/design`. Here you may find answers to why things are how they are (particulary in the object model).

## State of this project

The project is in the process of being rewritten (crate `everything_2`) with a different object model. This new crate merges previous crates `everything_objects` and `everything`. All other crates can be ignored for now.
